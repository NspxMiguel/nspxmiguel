### What I do

Web dashboards that fix a problem of my own, native apps for the Mac and the iPhone,
tooling for AI agents, and console work when something ought to run on hardware that was
never meant to run it. Everything ships with source, an installer and a tagged version.
Nothing parked at `WIP`.
